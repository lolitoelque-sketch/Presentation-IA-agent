# README v1 - .gitignore

Este README documenta el cambio nuevo realizado en `.gitignore`.

## Que se cambio

Se agregaron tres reglas nuevas:

```gitignore
*.zip
.agents
.codex
```

## Por que se modifico

Se modifico para preparar el proyecto antes de subirlo a GitHub.

El archivo `agentes-ia-slidev.zip` pesa mas de 100 MB, y GitHub rechaza archivos de ese tamano en commits normales. Por eso se agrego `*.zip`.

Tambien se agregaron `.agents` y `.codex` para evitar subir carpetas internas de trabajo del asistente o configuraciones locales que no forman parte de la presentacion.

## Paso a paso de la modificacion

1. Se abrio el archivo `.gitignore`.
2. Se conservaron las reglas existentes para `node_modules`, `dist` y archivos temporales.
3. Se agrego `*.zip` para ignorar archivos comprimidos generados localmente.
4. Se agrego `.agents` para ignorar datos internos del entorno.
5. Se agrego `.codex` para ignorar configuraciones locales del asistente si aparecen en el proyecto.

## Codigo de ejemplo

Este es el bloque agregado:

```gitignore
# Ignora archivos comprimidos generados localmente
*.zip

# Ignora carpetas internas del entorno de trabajo
.agents
.codex
```

## Resultado del cambio

El repositorio queda mas limpio y listo para GitHub. Se suben los archivos fuente de la presentacion, pero no el ZIP pesado ni carpetas internas locales.
